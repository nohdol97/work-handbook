# 압축형 AWS Cloud Basic 1~5장 매핑

- 최신 지정 원문: `aws_cloud_basic_ch01_ch05_compact_source.md`, 1,503행·24,577bytes. 한국어 core는 원문 그대로 보존하고 영어는 동일 구조로 번역했다.
- 이전 파일과의 관계: 사용자가 기존 `aws_cloud_basic_ch01_ch05_source.md` 반입을 롤백한 뒤 제공한 새 기준이다. 이전본 3,451행·48,720bytes는 비교에만 사용하고 복원하지 않았다. 이전 공개본과 원문은 Git 이력에 남으며 활성 batch로 되돌리지 않았다.
- 새 구성: 12장 과정에서 7장 과정으로 변경됐다. CIDR·IP가 2장 정규 절이 되고 ARN이 1.4에 추가됐다. ALB/NLB/Service는 3장, 스토리지와 DB/cache는 4장, EKS는 5장에 포함된다. 다음은 6장 AWS Managed Services다.
- 정규 페이지: `aws-cloud/index.md`, `foundations.md`, `networking.md`, `compute.md`, `storage-databases.md`, `eks.md` 한영 6쌍. 기존 55쌍을 61쌍으로 확장했다. 이전의 별도 storage/databases-cache 페이지는 복원하지 않았다.
- 출처 ID: 내용과 번호가 달라진 구성을 신규 AWSC 39개 ID로 추적한다. 이전 AWS-ID 반입은 사용자 요청으로 철회된 상태다. 기존 382개 활성 지식 ID를 유지해 총 421개다. 각 장의 상세 추출 항목은 해당 ID의 knowledge에 보존했다.
- 추출과 읽기: 페이지 작성 전에 번호별 개념·예시·수치·조건을 추출했다. 통합 담당이 1~22행·1415~1503행, 기본/네트워크 담당이 23~553행, 컴퓨트/스토리지 DB 담당이 554~1065행, EKS 담당이 1066~1414행을 읽고 이전 원문과 비교했다. 각 작성자가 원문과 양언어 페이지를 전문 재독했다.
- 독립 검토: 작성자가 아닌 담당자가 각 장의 원문과 한영 전체, 별도 보완, 실습을 읽고 의미·쉬운 영어·개인정보를 검토했다. 검토 후 파일 해시는 `reviews/bilingual.json`에 기록한다. 원문 구조와 수치 검증은 의미 검토를 대체하지 않는다.
- 개인정보: 계정·자격증명·개인정보·내부 운영 URL은 없다. 사설 IP·리소스 이름은 학습용 예시다. 원문의 업로드 파일명만 출처로 보존하고 사용자 로컬 경로는 게시하지 않는다.
- 중복·연결: 기존 플랫폼 Kubernetes/Redis/PostgreSQL/보안 문서는 유지한다. AWS 관리 서비스·IAM·network·EKS 실행 환경과의 관계는 같은 언어 링크로 연결한다. compact에서 제거된 이전 긴 본문을 보완으로 복원하지 않았다.
- 학습 경계: AWS 1~5장은 Basic 개념 학습이며, 6~7장은 후속 목차다. 원문은 Terraform/IaC를 다른 세션에서 다뤘다고 밝히지만 본문은 미제공이므로 기존 플랫폼 1~11장 공개 범위와 진도 기록은 유지했다.
- 권한: 문서 반영과 기존 Pages 배포 범위다. AWS 조회·리소스 생성·명령 실행·요금·성능·복구 검증은 수행하지 않았다.
- 공통 하네스 피드백: 최신 원문 비교, 구간 보존, 검토 해시, 페이지 수, 프롬프트, 화면 및 vault 검사를 재사용한다. 이번 자료 교체에서 추가 공통 규칙이나 도구 변경의 필요성은 확인되지 않았다.
