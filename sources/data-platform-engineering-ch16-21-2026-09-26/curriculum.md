# 후속 자료의 커리큘럼

자료는 Phase 1~21 개념 학습 완료를 선언한다. 새로운 본문은 16~21장에 한정하며 기존 1~15장 내용을 대체하지 않는다.

| Phase | 주제 | 제공 깊이 |
|---|---|---|
| 16 | AI 평가 데이터 플랫폼 | 16.1~16.12, online/offline·feedback·judge·버전·회귀·비용·장기 분석 |
| 17 | Databricks | 17.1~17.12, 구성 요소·상호운용·거버넌스·AI·비용·대체 범위 |
| 18 | Snowflake | 18.1~18.13, 요약된 구조·수집·변환·Iceberg·governance·AI·비용 |
| 19 | 플랫폼 비교 | 19.1~19.15, 소유·개방성·compute·workload·운영·lock-in·총비용 |
| 20 | 운영 엔지니어링 | 20.1~20.22, backfill·재처리·장애 시나리오·capacity·cost·DR·SLO |
| 21 | 통합 아키텍처 | 21.1~21.29, 역할·실패·일관성·축소·managed 대안·결정 질문 |

최종 mental model과 7개 설계 원칙도 정규 architecture에 병합한다. 학습 완료는 구축·운영 숙련도나 성능 시험의 증거가 아니다.
