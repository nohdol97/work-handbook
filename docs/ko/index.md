# Work Knowledge Handbook

업무에서 배우고 검증한 지식을 오래 쓰기 위한 핸드북이다. 개념 이해, 설계, 운영, 문제 해결, 프로젝트 진행과 LLM 활용에 필요한 지식을 정리한다.

## 현재 범위

학습 자료 1건에서 데이터 플랫폼의 기초 저장·이벤트·처리·분석·품질·관측·거버넌스·AI 데이터와 온라인 평가를 정리했다. 기술·구조·커리큘럼 18쌍, 실무 프롬프트 모음 18쌍, 홈·지식 관리 방법·용어집을 합쳐 한영 39쌍이다.

자료의 Phase 1~15 및 16.1은 개념 학습 범위다. Chapter 1~4는 원문이 복원된 노트라고 명시한다. Phase 16의 나머지와 Phase 17~21은 미학습 목차로 남겼다. 공부한 내용을 실제 구축·운영 경험으로 표현하지 않는다.

소프트웨어, 데이터, AI, 플랫폼, 인프라, 아키텍처, 운영 등 실제 자료가 들어온 분야부터 확장한다. 새로운 역할이나 기술을 기존 분류에 억지로 끼워 넣지 않는다.

## 바로 쓸 수 있는 실무 예시

[실무 프롬프트 모음](prompts/index.md)에서 주제별 새 예시 100개를 찾을 수 있다. 기존 17개 예시까지 모두 한국어·English 탭으로 선택하고 복사할 수 있다. 입력 자료·요청·출력·검증을 여러 줄로 구분했다. 예시는 실제 운영 결과가 아니라 학습 개념을 적용한 작성 템플릿이다.

## 읽는 방법

[데이터 플랫폼 전체 구조](data-platform/architecture.md)에서 각 도구의 역할을 파악하고, [학습 범위와 다음 과정](data-platform/curriculum.md)에서 필요한 주제로 이동한다. [지식 관리 방법](methodologies/knowledge-workflow.md)은 자료가 핸드북이 되는 과정을, [용어집](glossary/index.md)은 핵심 용어와 정규 주제 위치를 설명한다.

모든 공개 페이지에는 같은 지식을 담은 영어 페이지가 있다. 상단 언어 선택기로 같은 주제의 언어를 바꿀 수 있다.
