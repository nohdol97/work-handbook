# Work Knowledge Handbook

개념 이해, 설계, 운영과 문제 해결에 다시 쓰는 업무 지식 핸드북이다. 필요한 분야에서 학습하거나 업무 자료를 넣어 검토할 프롬프트를 선택한다.

## 현재 범위

| 분야 | 제공 범위 | 시작점 |
|---|---|---|
| 데이터 플랫폼 | 1~21장: 저장·처리·분석·품질·거버넌스·AI 평가·managed 플랫폼·운영 | [전체 구조](data-platform/architecture.md) · [학습 현황](data-platform/curriculum.md) |
| 플랫폼·인프라 | 1~15장: Linux·Kubernetes·AI 서빙·보안·GitOps·IaC·멀티테넌시·개발자 플랫폼·전체 구조 | [학습 경로와 완료 현황](platform-infrastructure/index.md) |
| AWS 클라우드 | 압축형 1~7장 완료: 계정·네트워크·EKS·관리형 서비스·보안·관측·GPU·전체 구조 | [학습 범위](aws-cloud/index.md) |
| 실무 프롬프트 | 설계·변경 검토, 장애 조사, 성능·비용 분석, 검증·복구 준비 | [업무별 예시 찾기](prompts/index.md) |

한영 67쌍이다. 장별 완료·미학습 범위와 다음 과정은 각 분야의 학습 현황에서 확인한다. 데이터 플랫폼 1~4장은 복원 노트이고 Snowflake는 요약 범위다. 학습 완료는 실제 구축·운영·장애 실험 완료를 뜻하지 않는다.

## 업무에 사용하는 방법

1. [실무 프롬프트 모음](prompts/index.md)에서 지금 결정할 업무에 맞는 사례를 고른다. 모음 100개와 본문 42개, 총 142개 예시가 있다.
2. 대괄호에 공개 가능한 비식별 SQL·설정·로그·지표·변경 내용을 넣는다. 부족한 자료는 누락으로 표시한다.
3. 한국어·English 탭에서 프롬프트를 복사하고, 결과의 근거와 검증 기준을 실제 자료에 대조한다. 실행·변경은 별도의 업무 권한과 절차를 따른다.

예시는 기존 학습 개념을 업무에 적용하기 위한 템플릿이다. 실제 모델 실행이나 효과를 측정한 사례집은 아니다.

## 원문과 보완 설명

학습 본문은 공유된 MD의 제목·번호·순서·문단·목록·예시를 유지한다. 원래 언어는 원문 그대로, 반대 언어는 같은 구조의 번역이다. 정정·적용 조건·추가 예시는 본문 뒤 보완 영역에서 원문 절과 연결한다.

## 읽는 방법

기술 용어는 [용어집](glossary/index.md), 자료 보존과 작성 과정은 [지식 관리 방법](methodologies/knowledge-workflow.md)을 참고한다. 실제 자료가 들어온 분야부터 확장하며 새로운 역할이나 기술을 기존 분류에 억지로 끼워 넣지 않는다.

상단 언어 선택기로 같은 주제의 한국어·영어를 전환할 수 있다.
