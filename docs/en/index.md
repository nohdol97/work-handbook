# Work Knowledge Handbook

This handbook keeps knowledge useful over time. It supports learning, design, operations, troubleshooting, project work, and practical LLM use.

## Current scope

The handbook starts with a knowledge workflow and a glossary. No study sources or curriculum have been imported yet. It does not claim that technical topics have been studied or used in real work.

Software, data, AI, platform, infrastructure, architecture, and operations can grow as sources arrive. New roles and technologies can add new domains.

## How to read it

The [knowledge workflow](methodologies/knowledge-workflow.md) shows how sources become handbook pages. The [glossary](glossary/index.md) defines terms used in that process.

Every public page has a Korean page with the same knowledge. Use the language menu to switch languages on the same topic.
