### get wrong {#idioms-get-wrong}

**134 occurrences · 54 documents · neutral**

**잘못 이해하거나 판단하다**

The usual pattern is get something wrong. In a question, the object can move to the front: What did we get wrong? Counts include only the listed forms.

> What could we get wrong about this requirement?
>
> 이 요구사항에서 우리가 잘못 이해할 수 있는 부분은 무엇인가요?

Counted forms: get wrong, gets wrong, got wrong, gotten wrong, getting wrong, get it wrong, gets it wrong, got it wrong, gotten it wrong, getting it wrong.

### in practice {#idioms-in-practice}

**53 occurrences · 44 documents · neutral**

**실제로, 실제 운영에서는**

This fixed expression contrasts theory with real use. Learn it as a collocation; it does not mean doing an exercise.

> In practice, the deployment may take longer.
>
> 실제로는 배포가 더 오래 걸릴 수 있다.

Counted forms: in practice.

Example source pages: [ai-model-development/qlora-training](../ai-model-development/qlora-training.md), [ai-model-development/training-datasets](../ai-model-development/training-datasets.md), [ai-model-development/training-platform-architecture](../ai-model-development/training-platform-architecture.md).

### instead of {#idioms-instead-of}

**45 occurrences · 30 documents · neutral**

**~ 대신에**

This fixed prepositional expression introduces an alternative. Follow it with a noun, pronoun, or -ing form, not a bare verb.

> Could we reuse the module instead of rewriting it?
>
> 모듈을 다시 작성하는 대신 재사용할 수 있을까요?

Counted forms: instead of.

Example source pages: [ai-model-development/model-developer](../ai-model-development/model-developer.md), [ai-model-development/model-retraining](../ai-model-development/model-retraining.md), [ai-model-development/qlora-artifacts](../ai-model-development/qlora-artifacts.md).

### rather than {#idioms-rather-than}

**30 occurrences · 22 documents · neutral**

**~보다는, ~하지 않고**

This fixed expression is a collocation for comparing alternatives. Matching the grammatical forms makes the comparison clear.

> Use measured latency rather than estimated latency when comparing the options.
>
> 선택지를 비교할 때는 추정한 지연 시간보다 측정한 지연 시간을 사용하세요.

Counted forms: rather than.

Example source pages: [aws-cloud/compute](../aws-cloud/compute.md), [aws-cloud/foundations](../aws-cloud/foundations.md), [aws-cloud/networking](../aws-cloud/networking.md).

### in other words {#idioms-in-other-words}

**18 occurrences · 9 documents · neutral**

**다시 말해**

This fixed linking expression is a collocation for restating an idea. Keep the original meaning rather than adding a new claim.

> The worker has no tasks. In other words, it is idle.
>
> 워커에 작업이 없다. 다시 말해 유휴 상태다.

Counted forms: in other words.

Example source pages: [ai-model-development/model-developer](../ai-model-development/model-developer.md), [ai-model-development/qlora-artifacts](../ai-model-development/qlora-artifacts.md), [ai-model-development/qlora-training](../ai-model-development/qlora-training.md).

### at the same time {#idioms-at-the-same-time}

**12 occurrences · 11 documents · neutral**

**동시에**

This fixed expression is a collocation for events happening together. The meaning here is time, not its separate use for adding a contrasting point.

> Can both jobs run at the same time?
>
> 두 작업을 동시에 실행할 수 있나요?

Counted forms: at the same time.

Example source pages: [aws-cloud/managed-services](../aws-cloud/managed-services.md), [aws-cloud/storage-databases](../aws-cloud/storage-databases.md), [data-platform/event-architecture](../data-platform/event-architecture.md).

### by default {#idioms-by-default}

**10 occurrences · 6 documents · neutral**

**별도로 바꾸지 않으면, 기본 설정으로**

This fixed expression is a collocation for the behavior used without an explicit choice. Name the product or setting because defaults can differ.

> Is this check enabled by default?
>
> 이 검사는 기본 설정으로 활성화되어 있나요?

Counted forms: by default.

Example source pages: [aws-cloud/ai-gpu-architecture](../aws-cloud/ai-gpu-architecture.md), [aws-cloud/compute](../aws-cloud/compute.md), [data-platform/spark](../data-platform/spark.md).

### at a time {#idioms-at-a-time}

**6 occurrences · 5 documents · neutral**

**한 번에**

This fixed expression is a collocation used after one or another quantity. It states how many things happen together; distinguish it from at the same time.

> Restart one worker at a time.
>
> 워커를 한 번에 하나씩 재시작하세요.

Counted forms: at a time.

Example source pages: [data-platform/spark](../data-platform/spark.md), [platform-infrastructure/architecture](../platform-infrastructure/architecture.md), [platform-infrastructure/kafka](../platform-infrastructure/kafka.md).

### as a result {#idioms-as-a-result}

**2 occurrences · 2 documents · neutral**

**그 결과**

This fixed linking expression is a collocation that introduces a consequence. Use it for a causal connection, not just events that happened together.

> The queue is full. As a result, new requests must wait.
>
> 큐가 가득 찼다. 그 결과 새 요청은 기다려야 한다.

Counted forms: as a result.

Example source pages: [data-platform/flink](../data-platform/flink.md), [platform-infrastructure/architecture](../platform-infrastructure/architecture.md).

### in advance {#idioms-in-advance}

**1 occurrence · 1 document · neutral**

**미리, 사전에**

This fixed expression is a collocation for doing something before an event or deadline. A time period can come before it: two days in advance.

> Please share the review notes in advance.
>
> 검토 메모를 미리 공유해 주세요.

Counted forms: in advance.

Example source pages: [platform-infrastructure/vllm](../platform-infrastructure/vllm.md).

### in place {#idioms-in-place}

**1 occurrence · 1 document · neutral**

**마련되어 있는, 준비되어 작동하는**

This idiom describes an established plan, process, or control. Use be in place or put something in place; the meaning here is not physical location.

> Is a recovery plan in place?
>
> 복구 계획이 마련되어 있나요?

Counted forms: in place.

Example source pages: [ai-model-development/training-platform-architecture](../ai-model-development/training-platform-architecture.md).

### make sense {#idioms-make-sense}

**1 occurrence · 1 document · neutral**

**이치에 맞다, 이해가 되다**

This idiom says that an idea is reasonable or understandable. Add to someone to name the person who understands it.

> Does this retry policy make sense for batch jobs?
>
> 이 재시도 정책은 배치 작업에 적절한가요?

Counted forms: make sense, makes sense, made sense, making sense.

Example source pages: [platform-infrastructure/vllm](../platform-infrastructure/vllm.md).

### in terms of {#idioms-in-terms-of}
