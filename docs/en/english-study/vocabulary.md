### check {#vocab-check}

**540 occurrences · 76 documents · neutral**

**확인하다; 점검**

Name the object directly, as in check the settings, or use check whether before a condition.

> Please check whether the retry limit changed in the latest release.
>
> 최신 릴리스에서 재시도 한도가 바뀌었는지 확인해 주세요.

Counted forms: check, checks, checked, checking.

### use {#vocab-use}

**511 occurrences · 76 documents · neutral**

**사용하다; 사용**

>
> 두 구현을 비교하기 위해 작은 테스트 데이터셋을 사용합니다.
