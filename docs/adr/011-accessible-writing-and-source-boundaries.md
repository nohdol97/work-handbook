# ADR 011: 원문 경계를 지키는 입문자 중심 설명

- 날짜: 2026-10-17
- 상태: accepted
- 관련 결정: [ADR 006](006-source-preserving-study-pages.md), [ADR 009](009-explicit-inline-additions.md)를 유지하면서 앞으로의 작성 방식에 적용

## 배경

기존 원문 보존은 누락과 임의 재구성을 막는다. 그러나 어려운 표현을 그대로 노출하면 처음 배우는 독자는 기술 간 관계와 사용 시점을 이해하기 어렵다. 사용자는 기존 목차와 핵심 내용을 보존하면서 앞으로의 문서를 쉽고 자연스럽게 개선하도록 요청했다.

## 결정

새로 작성하거나 개정하는 설명은 목차와 핵심 지식을 유지하며 쉬운 표현, 첫 용어 풀이, 필요한 비유·예시, 사용 이유와 시점, 기술 간 연결, 장별 핵심 정리를 제공한다. 보존은 의미 있는 기술 내용과 출처 추적을 포함한다. 원문 자료 자체는 기존처럼 보관한다.

이미 `reviews/source-preservation.json`에 등록된 구역의 byte 동일성은 계속 지킨다. 일반적인 쉬운 설명은 그 구역 밖에 둔다. 특정 등록 구역을 고쳐 쓰라는 명시적 후속 요청이 오면, 해당 구역의 보존 계약과 검증 변경을 별도로 설계·검토한다. 원문 사이 추가 설명에 관한 ADR 009도 그대로 적용한다. 이 결정만으로 기존 검사를 끄거나 등록을 삭제하지 않는다.

명시적 후속 요청의 한정된 개정 방식은 [ADR 012](012-scoped-source-rewrite.md)에 기록했다. 기본 보존 결정은 유지한다.

## 대안

- 모든 공개 원문을 즉시 재작성: 기존 보존 결정과 검증을 무너뜨리고 전체 페이지 검토 범위가 지나치게 커진다.
- 원문만 그대로 두고 설명 기준을 추가하지 않음: 사용자의 입문자 가독성 요구가 반복 작업에 반영되지 않는다.

## 결과

- 출처 보존과 독자용 설명을 구분해 이후 작성자가 적용 경계를 알 수 있다.
- 등록 원문이 있는 페이지에서는 별도 보완부 때문에 문서가 길어질 수 있어 반복을 줄이는 편집 검토가 필요하다.
- 문장 난이도와 비유의 정확성은 자동 검사로 판정할 수 없어 양언어 직접 검토가 필요하다.
