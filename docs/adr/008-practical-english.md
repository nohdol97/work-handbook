# ADR 008: 누적 문서에서 실전 영어 학습 자료 생성

- 상태: accepted
- 날짜: 2026-10-05
- 관련 결정: [ADR 003](003-handbook-and-vault.md), [ADR 006](006-source-preserving-study-pages.md)

## 맥락

사용자가 기존 문서와 이후 추가 문서를 활용해 한영 사전·숙어·관용 표현·구동사·구어체 및 면접/회사 문장을 빈도순으로 학습하도록 요청했다. 기존 기술 용어집은 개념 정의이며 이 목적의 어휘·화용 학습과 다르다.

## 결정

영어 정규 본문의 코퍼스와 사람이 검토하는 구조화된 학습 원고를 분리한다. 코드·메타데이터·URL·생성된 학습 페이지를 코퍼스에서 제외해 코드 token과 자기 집계에 의한 순위 왜곡을 줄인다. 명시된 활용형의 실제 출현 수로 분류별 정렬하고, 문서에 없는 구어·면접 보충 표현은 0회 구역으로 구별한다.

검토 원고는 `learning/english-entries.json`, 집계 근거는 `reviews/english-frequency.json`, 공개 파생물은 `docs/{ko,en}/english-study/`로 둔다. 전용 생성기는 파생물만 쓰고 기존 학습 원문은 변경하지 않는다. 생성한 Markdown도 기존 한영 의미 검토·사이트·vault 검증을 따른다. 코퍼스 변경 후 재생성이 빠지면 전체 검증이 실패한다.

## 대안과 결과

- 수동 빈도 숫자 관리: 문서가 추가될 때 쉽게 낡아져 제외한다.
- 코드와 원문 소스 폴더까지 모두 계산: 코드 식별자와 같은 내용의 중복 사본에 순위가 좌우되어 제외한다.
- 외부 일반 영어 빈도를 핸드북 빈도로 사용: 모집단이 달라 제외한다. 빈도는 이 핸드북 안의 학습 우선순위다.
- 모든 n-gram을 숙어로 자동 게시: 문법 조각과 자연스러운 표현을 구별하지 못하므로 후보만 자동 생성한다.

활용형 목록과 표현 설명을 검토하는 비용이 생긴다. 자동 정렬·최신성 검사는 이 검토를 대신하지 않는다. 추가 표현은 원문 출현·일반 구어 빈도·개인의 실제 업무 경험으로 주장하지 않는다. 새 외부 서비스·공개 대상·개인정보 수집 권한은 생기지 않는다.

## 검증

[스펙 008](../specs/008-practical-english.md)의 코퍼스 경계·횟수·정렬·생성·stale 검사 회귀와, 전체 한영 의미·화면·vault·배포 확인을 따른다.
