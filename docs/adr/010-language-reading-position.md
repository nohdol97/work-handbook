# ADR 010: 이동 가능한 언어 버튼과 읽기 위치 복원

- 날짜: 2026-10-06
- 상태: accepted
- 관련 결정: [ADR 003](003-handbook-and-vault.md)의 i18n 라우팅을 유지하는 추가 결정

## 배경

언어 메뉴는 같은 주제의 번역 페이지로 이동하지만 읽던 위치를 전달하지 않아 페이지 맨 위로 돌아간다. 한영 제목 ID는 번역에 따라 달라지거나 다른 제목에 같은 값이 붙을 수 있다. 번역 길이도 달라서 절대 스크롤 좌표만 복사하면 같은 내용을 유지하지 못한다. 현재 83쌍의 제목 수준 순서는 일치한다.

## 결정

유지되는 i18n 플러그인의 같은 주제 href를 재사용하고, 플로팅 언어 버튼과 읽기 위치 복원에 한정한 JavaScript를 추가한다. 버튼은 반대 언어(EN/한)를 표시하고 한 번에 전환하며 접근 가능한 이름을 제공한다. 정상 초기화 후 기존 드롭다운을 대체하고, JS가 실패하면 헤더 언어 메뉴를 유지한다. 일반 클릭·키보드 실행에서 고정 header 아래 16px를 기준으로 제목 순서, 구역 내 보이는 본문 블록 순서와 블록 내부 진행 비율을 기록한다. 숨긴 탭은 제외한다. 반대 언어에서 같은 순서로 복원하고, 블록 구조가 다르면 구역 진행률, 제목 구조가 다르면 문서 진행률로 대체한다. 맨 위와 맨 아래는 별도로 보존한다.

읽기 위치 metadata는 탭별 sessionStorage에 다음 목적지 경로와 함께 최대 60초 동안 보관하고 한 번 소비한다. 본문·개인정보나 서버 저장소는 추가하지 않는다. 저장소 접근 실패, 수정키 클릭과 새 탭은 기존 링크 동작을 유지한다. 다른 문서·재로드·뒤로가기에 낡은 위치를 적용하지 않는다. 늦게 변하는 레이아웃의 보정은 짧은 초기 기간에 한정하며 사용자의 스크롤·터치·키보드 조작이 시작되면 중단한다.

Alt+Shift+L(맥: Option+Shift+L)은 반대 언어 링크에 클릭과 같은 복원 경로를 적용한다. 언어 버튼 tooltip과 `aria-keyshortcuts`에 단축키를 알린다. 검색창·input·textarea·select·contenteditable, IME 조합·키 반복·추가 modifier에서는 실행하지 않아 입력을 방해하지 않는다.

버튼은 마우스·터치로 6px 이상 움직이면 드래그로 판정하고 종료 시 언어를 바꾸지 않는다. 화면 가장자리에서 12px 안쪽에 제한하며 리사이즈·회전 후에도 보이게 한다. 정규화된 버튼 좌표만 localStorage에 저장해 언어 전환·재방문 시 유지한다. 저장 실패 시 현재 페이지의 이동은 계속 동작한다. 버튼에 포커스가 있으면 화살표로 10px, Shift+화살표로 40px 이동하고 Enter/Space로 전환한다.

이는 기존의 사용자 정의 JavaScript 회피 원칙에 대한 언어 버튼·읽기 위치 기능만의 예외다. 원문·번역·URL 라우팅·배포 권한은 확대하지 않는다. 앞으로도 전체 사이트 감사에서 한영 제목 수준 순서의 일치를 검사한다.

## 대안

- 제목 hash 전달: 번역된 ID와 중복 ID가 같은 내용을 안정적으로 가리키지 못한다.
- 절대 scrollY 또는 문서 전체 비율만 전달: 번역 길이가 다른 긴 문서에서 구역이 어긋난다. 전체 비율은 구조 불일치 시의 대체 수단으로만 사용한다.
- SPA 전환이나 사용자 정의 언어 라우터: 읽기 위치 문제에 비해 변경 범위와 유지관리 비용이 크다.

## 결과

기존 정적 사이트와 i18n 탐색을 유지하면서 대응 구역에서 계속 읽을 수 있다. 제목·블록의 구조 대응을 유지하고 브라우저 레이아웃 회귀를 검증할 비용이 생긴다. 번역의 문장별 대응이나 모든 동적 레이아웃을 보장하지 않으며 사용자 입력 이후 강제로 위치를 되돌리지 않는다.

## 영향과 검증

스펙 004 R12–R19, 위치 복원·언어 버튼 JS/CSS와 등록 설정, 사이트 감사·회귀 테스트, README와 운영 계약에 적용한다. 링크 실행부터 반대 언어 복원까지 실패 재현 후 테스트하고 `make validate`, 하네스 검사, `git diff --check`, `make finalize`로 사이트·계약·vault를 확인한다. 실제 1280px·375px 브라우저에서 클릭·단축키의 한영 왕복 전환, 제목·문단·긴 코드·표·끝 위치와 버튼 클릭·드래그·키보드 이동·위치 저장·리사이즈를 확인하며 실행하지 않은 환경은 별도로 남긴다. 연결된 브라우저가 없으면 독립 headless 브라우저의 실제 렌더링으로 확인하고 그 범위를 기록한다. 이 ADR은 검증 계획이며 테스트 통과 증거를 대신하지 않는다.

JS 등록을 제거하면 기존 i18n 링크 동작으로 돌아간다.
