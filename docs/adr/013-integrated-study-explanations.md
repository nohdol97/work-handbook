# ADR 013: 필요한 보완을 원문 절에 통합

- 날짜: 2026-10-18
- 상태: accepted
- 관련 결정: [ADR 012](012-scoped-source-rewrite.md)의 범위 한정 개정을 이어받음

## 배경

원문을 보존하면서 끝에 별도 보완을 모으자 같은 개념의 정의와 실제 적용 조건이 떨어졌다. 사용자는 필요한 보완만 원문에 녹이고 원래 형식과 기술 깊이를 지키며, 앞으로도 같은 방식으로 문서를 작성해 달라고 요청했다.

## 결정

선택된 editable 구역에서는 필요한 기술 조건과 정정을 대응 절에 통합한다. 별도 보완 제목은 기본 형식이 아니다. 원래 제목·번호·순서와 기존 Markdown 구조를 유지하며, 추가 설명·예시·도식은 허용한다. 검사기는 원래 제목을 그대로 요구하고 기존 fence·목록·표·인용·구분선이 순서대로 남았는지 확인한다. 의미와 중복 여부는 원본·한영 문서의 직접 검토로 판단한다. AI 예시는 실제 도움을 줄 때만 둔다.

## 대안과 결과

별도 보완을 계속 쌓으면 작성은 쉽지만 독서 흐름이 끊긴다. 보완을 단순 삭제하면 정정·운영 안전 지식이 사라진다. 절별 통합은 검토 비용이 더 들지만 개념과 적용 조건을 같은 자리에서 읽게 한다. 사용자가 명시적으로 verbatim을 요구한 구역은 외부 설명이 계속 필요할 수 있다.

## 검증
