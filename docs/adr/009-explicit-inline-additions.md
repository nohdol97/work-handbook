# ADR 009: 명시적 요청에 따른 원문 사이 추가 설명

- 상태: accepted
- 날짜: 2026-10-06
- 관련 결정: [ADR 006](006-source-preserving-study-pages.md)의 기본 보존 규칙에 대한 추가 결정

## 배경

사용자가 Compression의 보충 설명을 원문 사이에 넣으라고 명시적으로 요청했다. 기존 검사기는 원문 구역의 모든 추가를 변조로 처리한다. 원문을 바꾸지 않으면서 요청한 위치에 설명을 넣고 그 경계를 검증할 방법이 필요하다.

## 결정

원문 밖에 보완을 두는 ADR 006의 기본값은 유지한다. 사용자가 원문 사이 추가를 명시적으로 요청한 경우에만 `reviews/source-preservation.json`의 해당 span에 선택적 `inline_additions`를 등록한다. 각 항목은 고유 marker, 공개 가능한 요청 증거, 한영 블록 SHA-256을 가진다.

한영 본문에서 추가 내용은 `INLINE ADDITION` START/END 주석으로 구분한다. 검사기는 등록·쌍·유일성·비중첩·양언어 hash가 유효한 블록만 비교용 문자열에서 제거하고 기존 원문 동일성·번역 구조 검사를 적용한다. 파일이나 저장된 원문은 변경하지 않는다. hash는 marker와 끝의 빈 줄(`\n\n`)까지 포함한다. 잘못된 등록이나 미등록·손상된 경계는 실패한다.

이 추가 결정은 원문 재작성·요약·삭제, 검증 우회 또는 임의의 원문 내부 보완을 허용하지 않는다. 사용자의 명시적 지시를 기록하는 방법이며 새로운 권한을 부여하지 않는다. ADR 006을 폐기하거나 일반 기본값을 대체하지 않는다.

## 대안과 결과

- 요청과 무관하게 모든 보완을 원문 밖에 유지: 사용자가 지정한 위치를 충족하지 못한다.
- 보존 source 자체 수정: 원문과 추가 설명의 구분 및 출처 추적이 사라진다.
- 모든 주석 블록 무시: 미등록 변경까지 검증에서 빠져 원문 보호를 약화한다.

추가 설명마다 등록과 한영 hash 검토가 필요하다. 자동 검사는 명시적 요청의 진위·내용의 정확성·번역 의미·가독성을 대신하지 않는다. 기존 전문 검토·렌더링·vault byte 검증과 공개 범위는 유지한다.

## 검증과 되돌리기

[스펙 006 R9–R11](../specs/006-source-preservation.md)의 등록·hash·경계·원문 변조 회귀로 검증한다. 설명을 원문 밖으로 옮기고 해당 등록을 제거하면 기존 기본 경로로 돌아간다. 저장된 source나 보존 검사 전체를 바꿀 필요가 없다.
