# ADR 012: 명시 요청 구역의 원본 추적형 본문 개정

- 날짜: 2026-10-18
- 상태: accepted
- 관련 결정: [ADR 006](006-source-preserving-study-pages.md), [ADR 011](011-accessible-writing-and-source-boundaries.md)의 기본 보존 원칙을 유지하며 명시 요청 예외를 정의

## 배경

사용자는 `data-platform`의 기존 원문 본문까지 입문자가 읽기 쉽게 고치고, 이후에도 이 스킬을 사용할 때 같은 방식을 적용하라고 명시했다. 종전 방식처럼 설명을 원문 밖에만 추가하면 본문 중간의 어려운 문장이 남는다. 기존 원본 파일과 지식 ID는 출처와 누락 검토에 계속 필요하다.

## 결정

등록 구역의 기존 기본 모드는 원문 동일성으로 둔다. 스킬이 문서를 작성·개정할 때 선택된 등록 구역만 `preservation_mode: editable`로 전환하고 사용자 상시 지시 및 현재 작업 범위를 증거로 남긴다. 사용자가 명시적으로 verbatim을 요구하면 원문 동일성을 유지한다. 개정 모드의 공개 문서는 원본의 출판용 개정본이며, 원본 파일은 그대로 보존한다. 검사기는 경계와 제목·번호·fence·목록·표·인용·구분선의 뼈대를 확인하고, 작성자는 원본의 의미 있는 사실·조건·예시와 한영 문서 전체를 직접 대조한다. 이번 문서 편집 범위는 `data-platform`뿐이다.

## 대안

- 원문 밖 설명만 추가: 본문 자체의 난이도를 낮추지 못한다.
- 등록을 삭제해 검사를 우회: 원본 연결과 변경 범위의 근거가 사라진다.
- 모든 등록 구역을 일괄 개정 모드로 전환: 요청하지 않은 영역까지 보존 계약이 약해진다.

## 결과

중간 본문을 직접 개선할 수 있고 출처 관계가 남는다. 자동 구조 검사는 의미 손실을 판정할 수 없으므로 원본·한영 전문 대조가 필수다. 기존 byte 보존 구역은 계속 기존 검사로 보호한다.

## 영향과 검증

영향: 보존 등록·검사·회귀, 루트 및 핸드북 계약, `preserve-study-source` 스킬, README·스킬 목록·문서 지도. 검증은 [스펙 010](../specs/010-requested-source-rewrite.md)의 R1–R4에 따른다.
