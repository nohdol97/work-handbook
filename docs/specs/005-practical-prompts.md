# 스펙 005: 읽기 쉬운 한영 실무 프롬프트

- 상태: active
- 날짜: 2026-09-24

## 문제와 목표

일부 기존 예시 프롬프트는 한 줄이며 좁은 화면에서 가로로 읽어야 한다. 한국어 페이지에서도 영어 prompt만 제공된다. 사용자가 바로 수정·복사할 수 있는 다양한 실무 예시와 두 언어 전환이 필요하다.

## 범위

기존 17개 예시를 보존·재구성하고, 기존 16개 데이터 플랫폼 학습 주제에 각각 6개 및 지식 관리에 4개를 추가한다. 새 예시 100개는 학습 자료의 개념에서 파생한 작성 예시이며 실제 업무 빈도 조사나 모델 실행 성능을 주장하지 않는다. 미학습 Phase의 학습 상태를 바꾸지 않는다.

## 요구사항과 인수 기준

- R1. 모든 예시 prompt는 여러 줄로 입력·요청·출력·검증을 구분한다. 전용 prompt code block은 375px·1280px 화면에서 줄바꿈을 보존하고 긴 문자열도 가로 overflow 없이 읽힌다. 일반 SQL·Mermaid 코드 스타일은 보존한다. 실제 브라우저의 computed style과 너비 및 복사 내용으로 검증한다.
- R2. 각 예시에는 `한국어`, `English` 탭이 있고 같은 요구·제약·입력·출력을 전달한다. 클릭·키보드 전환과 복사를 실제 UI에서 확인한다. 문서 전체 언어 전환은 기존 i18n을 사용한다.
- R3. 새 100개 시나리오는 17개 주제 문서에 나누고 모음에서 주제와 목적을 찾아 이동할 수 있다. 기존 예시와 정규 개념 페이지에서도 관련 모음으로 연결한다. 생성 산출물의 100개 고유 anchor와 언어별 동일 집합을 검사한다.
- R4. 각 시나리오는 상황, 제공 맥락, prompt, 기대 결과, LLM 오류 가능성, 검증 방법을 갖는다. 도메인별 입력·실패 조건·검증 증거가 구체적이며 범용 문장의 기계적 반복으로 개수를 채우지 않는다. 전체 한영 직접 검토와 해시 기록으로 확인한다.
- R5. 원문 기술 지식 151개와 canonical ID·미학습 상태를 보존한다. 파생 prompt는 기존 정규 지식을 링크하고 원문에 새 지식 ID나 실제 경험을 꾸며 넣지 않는다. 원문 추적 검사와 diff 검토를 수행한다.
- R6. 공개 페이지에는 실데이터·비밀값 없이 placeholder만 사용한다. prompt는 관찰·가설·누락 근거·검증을 구분하며, 실제 production 실행 권한을 새로 부여하지 않는다.
- R7. 닫힌 code fence, 두 언어 prompt, 여러 줄, 시나리오 anchor를 회귀 검사한다. `make validate`, `git diff --check`, `make finalize`, 원격 SHA·배포 HTTP로 전달을 확인한다.

## 검증 방법과 권한

표시 설정과 CSS는 기존 페이지의 한 줄 prompt를 재현하고 렌더링 회귀 검사가 먼저 실패하는 것을 확인한 뒤 변경한다. 새 문서의 의미·자연스러운 번역은 자동 검사로 증명하지 않고 담당자와 독립 검토자가 직접 읽는다. 화면 표시는 브라우저로 검증하며 HTML 구조 검사로 대체했다고 주장하지 않는다. 모든 실제 모델 호출·DB 질의·장애 실험은 범위 밖이다.

기존 승인된 저장소와 Pages 배포·vault 사본만 갱신한다. 새 서비스·외부 destination·사용자 권한 변경은 없다.
