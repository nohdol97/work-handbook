# 스펙 011: 원문 절에 통합하는 학습 문서

- 상태: active
- 날짜: 2026-10-18
- 관련 결정: [ADR 013](../adr/013-integrated-study-explanations.md)

## 문제와 범위

별도의 ‘원문 적용 시 보완’이 길어지면 독자는 같은 개념을 두 곳에서 읽어야 한다. data-platform 밖의 기존 학습 문서와 이후 `preserve-study-source`로 작성하는 문서에, 개념 이해 → 실무 판단 → 필요한 AI 활용이 자연스럽게 이어지는 기준을 적용한다. 학습 기록인 목차 페이지와 별도 프롬프트 모음은 역할에 맞게 편집한다.

## 요구사항과 인수 기준

- **R1. 원문과 정보 보존.** 선택한 등록 구역만 요청 증거와 함께 `editable`로 전환한다. 원래 제목·번호·순서와 기존 fence·목록·표·인용·구분선은 순서대로 남긴다. 필요한 설명이나 예제의 추가는 허용한다. 삭제·변형된 원래 구조는 실패한다. 원본 파일·지식 ID는 그대로 둔다.
- **R2. 보완 통합.** 별도 보완의 기술 사실, 정정, 운영 위험, 보안 조건, 인용과 유용한 도식은 대응 원문 절에 둔다. 내용과 연결 위치를 직접 대조한 뒤 반복 설명과 빈 보완 구역을 제거한다. 출처의 알려진 오류는 본문에서 고치고 원래 주장·정정 근거는 검토 기록에 남긴다.
- **R3. 읽기 흐름.** 각 장은 어려운 용어와 동작 원리를 쉬운 표현·정확한 일상 비유로 설명하고, 언제 쓰는지·실무 문제·판단 기준을 관련 절에서 다룬다. 세 관점을 고정 제목이나 동일 분량으로 강제하지 않는다. 필요할 때 짧은 핵심 정리를 둔다.
- **R4. AI 실전.** 조사·개발·디버깅·설계·검증에서 실제로 도움이 되는 경우에만 한영 탭의 짧고 자연스러운 요청을 제공한다. 목표·필요한 맥락·중요 제약만 넣고 형식 표지와 불필요한 절차를 없앤다. 결과를 판단할 근거와 운영 안전·데이터 보호·승인 조건은 가까운 설명에 유지한다. AI 예시가 없는 장도 허용한다.
- **R5. 한영·전달.** 양언어 전체와 등록 원본을 대조하고 review hash를 갱신한다. 영어 학습 생성물을 다시 확인한다. `make validate`, 원문 보존 검사, 대표 렌더링, `make finalize`의 vault byte 검사와 원격 배포 확인을 수행한다. 자동 검사는 의미·가독성 검토를 대신하지 않는다.

## 비목표

- 학습 예시를 실제 운영 실적으로 바꾸거나 외부 시스템의 명령을 실행하지 않는다.
- 사용자가 verbatim을 명시한 구역의 문장을 개정하지 않는다.
- 모든 장에 AI 예시나 ‘보완’ 절을 새로 만들지 않는다.
