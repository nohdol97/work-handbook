# ADR template

```markdown
# ADR NNN: 제목

- 날짜: YYYY-MM-DD
- 상태: proposed | accepted | superseded | rejected
- 대체/피대체: 해당할 때만 기록

## 배경

어떤 힘과 제약 때문에 결정이 필요한가.

## 결정

무엇을 선택하며 적용 범위와 firing condition은 무엇인가.

## 대안

- 대안 A: 장점, 단점, 기각 이유
- 대안 B: 장점, 단점, 기각 이유

## 결과

- 긍정적 결과
- 비용 또는 부정적 결과
- 후속 작업

## 영향과 검증

- 영향 파일·시스템
- 결정이 구현됐음을 확인하는 명령 또는 관찰 표면
```
